Link and preflight

Preflight is read-only: it arms nothing and writes no parameter. Over the radio it must be GO within the last 10 minutes before a props-on run can be authorised. It checks the ground link, the right backpack, one relay, link loss and delay, the abort flag, and the aircraft's heartbeat.

Mission profiles

A profile is a saved offboard test: which aircraft, which link, how far through the flight to go, and the numbers the controller flies. Deleting archives to profiles/deleted/.

Draw the area

    
Click on the map to draw the geofence, the area of operation (inside the fence) and the launch point. Drag a corner to move it. To keep the drones out of something inside the area, draw the area around it (a notch): the planner routes around a notch. Save makes a KML under ops/ that the planner below uses.

    

     
     
     
     
     
    

    

    

    

    

    

   

   
Plan a mission from a KML

    
Upload a sector KML with placemarks GCSlocation (a point), GeoFence and OpsArea (polygons). The planner splits the OpsArea between the drones, stacks them in altitude layers and checks separation; a refusal is shown, never worked around. Output goes to a new missions/<site>-<date>/ folder, one plan per drone, ready for a Fleet profile.

    

    

    

    

     
     
     
     
    

    

    

   

   
Missions on the map

    
Each drone's planned path, drawn from its .plan file: what the agent uploads. On board means an agent read that mission back from the aircraft in a Fleet run and the item count matched. It is not QGC's view, which goes stale.

    Fleet profiles
    
    
    A fleet profile is a multi-aircraft waypoint run: which aircraft, each one's mission plan, and how far to go. Plans come from one planning run (one mission_drones folder), so the separation guardrail covered them together. Archived profiles go to profiles/fleet/deleted/.

      1Authorise this fleet run
      
    
      
    
      
   
      
   
      
    
      2Prepare, then the two gates
      
    
      Prepare starts one agent per aircraft: it uploads and reads back the mission and runs the preflight contract, then holds the link. Every aircraft must be READY or nobody arms. Indoors there is no GPS fix, so a real aircraft stops at NOT READY; use "Upload and verify" there.
      
    
      
    
      
    
      
    
      
     
     
    
      
    
      
    
      
    
      3While they fly
      
    
      Each pilot's handset is the real override (ch5 OFF, or ch8 kill held 5 s). If one aircraft faults, the others are put in HOLD automatically. These buttons go through the agents and the radios.
